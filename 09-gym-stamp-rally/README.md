# ジムスタンプラリー（Let's Go Mt.Fuji！！）

妻のジム通いを習慣にするための LINE Bot。週に1回ジムに行ったらスタンプを押し、
10月後半から7月後半まで、40マスで富士山（7月の富士登山）を目指す。

- 初めて動かすときの手順 → [SETUP.md](SETUP.md)
- このファイル → 今の仕様と、決めた理由、直すときに見る場所
- ID・URL などの控え → `LOCAL.md`（手元だけ。GitHub には入れない）

---

## 何ができるか

| 場面 | 動き |
|---|---|
| ジムに行った | LINE のメニュー「スタンプラリー」→ 画面の「今週ジムに行った！」で1マス進む（**週1回まで**） |
| 押したとき | 画面にほめる表示（タップで閉じる）。本人の LINE に「えらい！…」、夫の LINE にお知らせ |
| 同じ週にもう1回行った | メニュー「コイン」→「今週もう1回行った！」でコイン1枚（**1日1枚まで**。その週のスタンプを押したあと） |
| 今週は行けない | 「コインを使う」でコイン1枚を使い、その週も行ったことにする。あとで行けたら「スタンプに変える」でコインが戻る |
| コインが5枚 | 「ご褒美と交換する（5枚使う）」か「ためておく」を選ぶ。ためておくと下に行が増え、6枚目以降もためられる |
| 水曜20時台 | 今週まだなら「今週のジム、行けそう？」 |
| 日曜17時台 | 今週まだなら「行けそう？」。コインがあれば「コインを使う」ボタン付き（押すとその場で穴埋め） |
| 押し間違えた | 画面の一番下「最後のスタンプ（コイン）を1つ消す」。ご褒美の箱を開ける前なら右上の × で取り消し |
| 押したマスを見返す | 押したマスをタップすると、押したときの画面が出る（紙吹雪・クラッカーなし） |
| 進み具合 | `状況` と打って送ると返信（メニューには置いていない） |

### ご褒美

| マス | 週1で続けた場合 | 種類 | 中身 |
|---|---|---|---|
| 6 | 11月末 | プチ | マッサージ |
| 11 | 12月末 | ご褒美 | 登山靴 |
| 18 | 2月中旬 | プチ | マカロン |
| 24 | 3月末 | ご褒美 | ジャケット／パンツ |
| 31 | 5月中旬 | プチ | マッサージ |
| 37 | 6月末 | ご褒美 | 帽子とサングラス |
| 40 | 7月後半 | ゴール | 富士山へ出発！ |
| コイン5枚 | — | 交換 | 手作りお菓子 |

- ご褒美のマスは、画面では中身を伏せて「プレゼント箱」だけ見せる。押すと箱が揺れて爆発し、中身と絵が出る（ご褒美はクラッカー付き、プチは控えめ）
- **本人へのメッセージには中身を書かない**（通知のプレビューでばれないように）。**夫には中身も書く**（準備のため）
- 夫への「止まりました」は、本人が箱を**開けた時点**で送る（× で取り消したときは送らない）

## 決めたこと（と理由）

| 決めたこと | 理由・経緯 |
|---|---|
| マス＝40（10/19の週〜7/19の週）、ご褒美は**マス数**で出す | 「12月末・3月末・6月末にご褒美」の要望を、週1で続けたときの位置（11・24・37マス目）に置いた。休んだ週はコインで埋めればずれない |
| 休んでもマスは減らない | 責める仕組みにしない。代わりにコインで穴埋めできる |
| 同じ週の2回目以降はコイン | 週1を超えて行ったぶんを、行けない週の保険・ご褒美に回せるように |
| スタンプの絵柄は押すまで分からない（6種からランダム） | 押す楽しみのため。選ぶ欄は作らない |
| ほめる画面は自動で閉じない | 本人の要望（タップで閉じる） |
| メッセージに「開く」ボタンを付けない | 本人の要望。画面はリッチメニュー（2つ）から開く |
| リッチメニューは「スタンプラリー」「コイン」の2つ、2500×1200 | 「状況」は不要とのこと。大きめが見やすい |
| 画面は GitHub Pages の枠ページ（`docs/gym/`）経由で開く | GAS を直接開くと、公開範囲に関係なく上に Google の注意バーが出るため |
| 白基調・明るい色、季節の絵は控えめ | 本人の要望。季節は上から 秋→冬→春→梅雨→夏 の順。すごろく（道とマス）より目立たせない |
| 夫と本人で LINE の宛先を分ける | `PLAYER_USER_ID`（声かけ・ほめる言葉）と `WATCHER_USER_IDS`（お知らせ） |

| 直したいもの | 場所 |
|---|---|
| ご褒美の中身・位置、コインのご褒美 | `logic.gs` の `GYM_SPECIAL`・`GYM_COIN_REWARD` |
| ほめる言葉 | `logic.gs` の `GYM_PRAISES`・`GYM_COIN_PRAISES` |
| マス数・期間 | `logic.gs` の `GYM_TOTAL`・`GYM_LAST_WEEK`（マス数を変えたら `web.html` の行数 `ROWS` と道の高さ `H` も） |
| 声かけの文面 | `main.gs` の `MIDWEEK_LINES`・`WEEKEND_LINES` |
| 声かけの曜日・時刻 | `main.gs` の `setupTriggers`（直したら GAS で `setupTriggers` を実行し直す） |
| LINE に送る文面 | `main.gs` の `notifyAfter_` |
| 画面の見た目・ご褒美の絵 | `web.html`（ご褒美の絵は `REWARD_ART`、季節の絵は `DECO`・`SEASONS`） |
| メニューの画像 | `richmenu.html` → `node richmenu.mjs` → GAS で `setupRichMenu` |

### 反映の手順（毎回）

```bash
cd 09-gym-stamp-rally
node test/gas.test.js        # サーバー側の確認（55項目）
node test/web.test.mjs       # 画面の確認（Edge・スマホ幅、38項目）
```

デプロイ ID は `LOCAL.md` にある。**`clasp deploy` を忘れると、LINE と画面は古いまま**動く。

## ハマりどころ（実際に起きたこと）

- **GAS エディタを開きっぱなしにしていると、`clasp push` した最新版を古い内容で上書きしてしまう。**
  push のあとは、エディタのタブを必ず再読み込み（F5）してから操作する。
  おかしいと思ったら `clasp clone <スクリプトID>` を別フォルダに取り、手元と比べる。
- **`/dev` と `/exec`**：GAS エディタから実行すると `/dev` の URL が返ることがある。LINE と画面に使うのは `/exec`。
  スクリプトプロパティ `WEB_EXEC_URL` に、デプロイ時に表示された `/exec` の URL を入れてある。
- **`[hidden]` の CSS**：試作（Claude の Artifact）では自動で付いていた `[hidden]{display:none!important}` が
  GAS には無く、ほめる画面などが最初から全部出ていた。`web.html` の先頭に入れてある。消さないこと。
- **読み込み・記録中に画面が黒く細くなる**：処理中に body へ付けるクラスを `busy` にしていたため、
  「記録中…」バッジ用の `.busy`（固定位置・濃い背景）が body 全体に効いていた。今は `is-busy`。
  模擬サーバーの返事が速いと気づけないので、`web.test.mjs` は返事を遅らせて確かめている。
- **トークンが違うときの案内**も `setXFrameOptionsMode(ALLOWALL)` にしないと、枠ページの中で空白になる。
- **`clasp create` は `appsscript.json` を初期値（ニューヨーク時間・Web アプリ設定なし）で上書きする。**
  作り直すときは元に戻してから push する。
- **スプレッドシートの「記録」シート**：ドライブで作ったスプレッドシートでも、`SPREADSHEET_ID` を入れれば
  最初の記録のときに先頭のシートが「記録」に整えられる（`main.gs` の `sheet_`）。
- **LINE の「開く」ボタンが消えない**ように見えるのは、最後に届いたメッセージのボタンが残っているだけ。次のメッセージで消える。

## 試作（デザインの元）

最初の試作は Claude の Artifact（非公開）にあり、同じものを `prototype/gym-stamp.html` に置いてある。
デモ用のボタン（1日進める・次の週へ・5週ぶん進める）と、LINE の見え方のイメージが付いていて、
仕様の相談をするときに便利。今の画面の正は `web.html`（試作を直しても本番には反映されない）。
Artifact 用のファイルなので、ブラウザで直接開くとほめる画面などが出たままになる（`[hidden]` の CSS が無いため）。
見るときは Artifact の URL（`LOCAL.md`）か、Artifact に公開し直して見る。
